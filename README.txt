Suleiman Birthday Website - source code
=======================================
index.html  - page structure
style.css   - royal blue / cream / gold theme
data.js     - ALL editable content (names, captions, moments, letter, love cards, messages, image paths)
main.js     - animations and interactions (GSAP ScrollTrigger)
images/     - photos (swap files or edit paths in data.js)

Run: open index.html, or serve the folder (e.g. `npx serve` or `python3 -m http.server`).
Deploy: upload the whole folder to Netlify Drop / GitHub Pages / Vercel.
Moments: add "d":"14 Feb" to a moment for a date (never add a year). art:1 tags AI-generated images.
Audio: not included; add a song/voice file and a player if wanted.
